# Full Stack Development & MERN Mastery

Comprehensive full-stack development curriculum, interactive LMS portal, study notes, interview banks, practice exercises, and compiled PDF guides.

## 📁 Repository Overview

- **`mern-mastery/`**: Complete 24-week curriculum covering JavaScript, TypeScript, React, Next.js, Node.js, Express, MongoDB/PostgreSQL, System Design, LLD, and DSA.
  - **`lms/`**: Interactive LMS web interface with dark mode, markdown rendering, and study dashboard.
  - **`notes/`**: Structured study notes across all core modules.
  - **`practice/`**: Weekly practice challenges and interview banks.
  - **`pdf/`**: Formatted PDFs for offline study and quick revision.
- **`Full stack development/`**: Supplementary web app and curriculum assets.

## 🚀 Getting Started

To launch the LMS locally:

```bash
# Navigate to the LMS directory
cd mern-mastery/lms

# Open index.html in your browser or run a static server
npx serve .
```
