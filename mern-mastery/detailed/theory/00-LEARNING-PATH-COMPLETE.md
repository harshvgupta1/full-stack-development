## Phase details

### PHASE 0 — Web fundamentals (Days 0–3, before React)

**PDF:** `00b-html-css-web-fundamentals-complete.pdf`

| Topic | Why before React |
|-------|------------------|
| HTML semantic tags | JSX compiles to HTML |
| CSS box model, flexbox | Tailwind/CSS modules |
| DOM API | React virtual DOM comparison |
| HTTP request in browser | fetch, CORS later |

**Skip if:** You built multi-page websites before.  
**Exercise:** Build static portfolio page (no JS framework).
