## 2. Twelve process families (memorize these)

### F1 — Google-like

`S1 → S2 → S6 (phone DSA) → loop: S6×2–3 + S15 (Googleyness) [+ S13 if L5] → S16 team match → hiring committee → offer`

Companies: **Google, YouTube, DeepMind-adjacent SWE, some Apple IC.**  
Skip: OA for most experienced SWE (campus/new-grad may have OA).  
Prep: unseen mediums + follow-ups. No memorized tagged-only list.

### F2 — Meta-like

`S1 → S2 → S6 (2 mediums / 45 min) → loop: S6×2 + S13 + S15 → S16 team match → offer`

Companies: **Meta, Instagram, WhatsApp, some Reality Labs.**  
Prep: Meta-tagged speed + feed/chat/typeahead HLD + impact stories.

### F3 — Amazon-like

`S1 → S2 → S3 + S4 → loop: S6 + S12 + S15×2 including **bar raiser** → S16`

Companies: **Amazon, AWS, Audible, Prime Video, Amazon India, some Walmart Global Tech.**  
Prep: OA week + LPs in *every* round + LLD (locker, rate limiter).

### F4 — Microsoft-like

`S1 → S2 → S3 or S6 → loop: S6×2 + (S12 or S13) + S14 sneak + S16 HM → as-appropriate → offer`

Companies: **Microsoft, LinkedIn, GitHub, some Xbox.**  
Prep: clean compilable DSA + CS pack + practical design.

### F5 — Uber / marketplace-like

`S1 → S2 → S3 (CodeSignal) → S6 → loop: S6 + S13 (maps/dispatch) [+ S11 on FE] → S16`

Companies: **Uber, Lyft, DoorDash, Ola, Swiggy (delivery), Zepto, Blinkit.**  
Prep: graphs, heaps, intervals + geospatial HLD.

### F6 — Atlassian / collaboration-like

`S1 → S2 → S5 (Karat) or S6 → loop: S11 or S10 + S7 + S15 values → S16`

Companies: **Atlassian, Slack, Notion-like, Zoom (sometimes), Monday-like SaaS.**  
Prep: frontend MC + a11y + values stories.

### F7 — Indian product / unicorn

`S1 → S2 → S3 (HackerRank/HackerEarth) → S10 (90 min) → S6 → S13 → S16 HM`

Companies: **Flipkart, Myntra, PhonePe, Razorpay, CRED, Groww, Meesho, Dream11, ShareChat, Freshworks (hybrid).**  
Prep: machine coding is the filter. HLD is SDE2+.

### F8 — Enterprise SaaS

`S1 → S2 → S3 → S7 (JS/Java) + S6 → S13 + S16 HM`

Companies: **Adobe, Salesforce, Oracle, SAP, ServiceNow, Workday, Intuit, Sprinklr, Freshworks, Zoho (Zoho is more take-home/HM).**  
Prep: production JS + one product HLD + less “Google hard.”

### F9 — Payments / fintech

`S1 → S2 → S3 → S6 + S13 (payments, idempotency) + S7 SQL + S16`

Companies: **Stripe, PayPal, Block, Visa, Mastercard, Amex, PhonePe, Razorpay, Paytm, Pine-like, Juspay-like.**  
Prep: payment HLD (PDF #10) + Ticketmaster locks + SQL.

### F10 — Consumer / media / ads

`S1 → S2 → S6 → S13 (feed, video, ads) + S15 → S16`

Companies: **Netflix, Spotify, Pinterest, Snap, Reddit, X, ByteDance, InMobi, ShareChat.**  
Prep: YouTube/feed HLD + ranking talk at a high level.

### F11 — Infra / data / security (MERN is a stretch)

`S1 → S2 → S3/S6 → S6 hard + S13 infra + often Java/Go/C++`

Companies: **Databricks, Snowflake, Confluent, Datadog, Cloudflare, CrowdStrike, Palo Alto, Nutanix, Rubrik, Elastic, HashiCorp, NVIDIA, Intel, Qualcomm, Cisco.**  
**Honest:** apply only if the *role* is fullstack/UI. Do not rebuild the syllabus for compiler jobs.

### F12 — Banks / trading-tech / take-home startups

**Banks:** `S1 → S2 → S3 → S6 + S14 + S15 → S16`  
**Startups / tools:** `S1 → S2 → S8 or S9 → S16 HM`  

Companies: **Goldman, JPMC, Morgan Stanley, Bloomberg, Capital One, DE Shaw (more DSA), Postman, BrowserStack, GitLab, Shopify (often pair), Coinbase.**

## 4. Stage scripts that were missing (do these)

### 4.1 Recruiter screen (S2) — 20 min — all 100

They are not testing DSA. They are testing **level, logistics, and whether you waste a loop**.

**Script:**
1. 60-sec “tell me about yourself” (PDF #16) — current work → TaskFlow/ShopLite metric → why this company.  
2. Notice period / serving / buyout — one sentence, no drama.  
3. Comp: “I’m targeting market for [L4/SDE2] in India, around **X–Y L TC**. Happy to talk after the loop.” Do not dump current CTC first.  
4. Role: fullstack / FE / Node — confirm stack. If they say Java-only, walk away (PDF #21).  
5. Ask: team, loop shape (write down S-numbers), location, hybrid.

**Drill (Day 170):** record a 20-min mock with a friend as recruiter. No code.

### 4.2 OA platforms (S3) — extras beyond PDF #21

| Platform | Quirk | Practice |
|----------|-------|----------|
| HackerRank | Hidden tests; `stdin` | HR editor only, 70 min |
| CodeSignal | Score /850; 4 Qs | Arcade + one certified |
| Codility | Correctness + performance | Worst-case complexity or you get 50% |
| HackerEarth | Common in Indian unicorns | Same as HR |
| Amazon OA | 2 DSA + work sim | PDF #21 + §4.3 |

**Codility extra:** after your solution, state complexity in a comment. They auto-fail O(n²) on n=1e5.

### 4.3 Amazon work-style survey (S4)

16 Leadership Principles. Pick the **customer / ownership / dive-deep** option, not the “wait for manager” option. Be consistent across questions (don’t be hero on one and passive on the next).

**Drill:** read Amazon LP one-liners (PDF #16). 20 min. Do not overthink.

### 4.4 Karat / third-party (S5)

- 60–75 min, often **API design + light coding** or 1–2 DSA.  
- Interviewer is a contractor — they follow a rubric. Speak more than in a Google round.  
- Atlassian: expect autocomplete-like API (`GET /suggest?q=`) + complexity.

**Drill (Day 173 extra):** 45 min — design autocomplete API aloud, then code the in-memory trie. Same as FE MC without React.

### 4.5 Take-home (S8)

Time-box **6–8 hours**. README: assumptions, how to run, tradeoffs, what you would do next. Tests on the core rule. No extra framework for show.

**Drill:** one weekend in Phase 9 or Day 171 — extract ShopLite checkout into a tiny repo with README + 3 tests.

### 4.6 Pair programming (S9)

You drive. Narrate. Ask before a big rename. Tiny steps. If stuck 3 min, say the brute force.

**Drill:** 45 min with a friend on LC 56 — they may only ask questions.

### 4.7 Bar raiser (S15 Amazon)

A trained interviewer from **another team**. They can veto. They push on **one LP** until the story has numbers. Prepare 2 stories with metrics you can defend for 15 min.

**Drill (Day 177):** one story, 15 min of “what was *your* decision?” follow-ups.

### 4.8 Hiring manager (S16)

Questions: why this team, hardest bug, underperforming peer, 2-year plan, system you would rewrite.  
**Level signal:** talk scope (users, latency, who you influenced), not tasks.

**Drill:** Day 180 (already in Phase 8D).

### 4.9 Team match (Google / Meta)

After “hire,” you talk to 2–4 teams. This is **not** another DSA. It is: what the team owns, on-call, stack, how you would ramp.

**Ask:** what failed last quarter, what the new hire owns in 90 days, FE vs BE split.  
**Fail:** only talking compensation, or saying you refuse on-call.

**Drill (Day 181):** 10-min pitch: “I want a product fullstack team on a user-facing surface (feed, checkout, or collab).”

### 4.10 Hiring committee, offer, BGV

- **HC (Google):** packet of notes. You cannot “study” this. You already did — every round’s notes must show hire.  
- **Offer:** PDF #17 Tier 5 + PDF #21 §8 (1 Cr is TC, not year-1 cash).  
- **BGV:** dates on resume must match. Do not inflate title. Notice-period letter ready.
